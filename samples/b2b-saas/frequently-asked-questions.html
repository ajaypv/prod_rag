NimbusFlow Frequently Asked Questions

This is fictional test documentation for the prodRAG demo.

Billing

Where can a workspace owner download an invoice?

Open Settings > Billing > Invoices. Monthly invoices normally appear within two hours of the billing run. If an invoice is still missing after 24 hours, route the ticket to Billing Operations.

What happens after a card payment fails?

NimbusFlow retries the payment after 1 day, 3 days, and 7 days. The workspace remains active during the seven-day grace period and becomes read-only only if the third retry fails.

API limits and authentication

What should a client do after HTTP 429?

Honor the Retry-After header, then retry with exponential backoff and jitter. Stop after five attempts. API limits apply per workspace, so creating another API key does not bypass the limit.

How does an administrator rotate an API key?

Open Settings > Developers > API keys, create the replacement key, update the application, verify a test request, and revoke the old key. Both keys may overlap for up to 15 minutes during a scheduled rotation.

Integrations

How do I recover from a Salesforce invalid_grant error?

Open Settings > Integrations > Salesforce, select Reconnect, sign in, and approve access again. Reconnecting preserves the existing field mapping.

Human review

Which questions must be handled by customer support?

Human review is required when retrieval confidence is low, when the documentation does not contain enough evidence, or when a ticket contains sensitive data such as a credential, payment-card number, or government identifier. Customers should remove sensitive values and use the approved secure support channel.
