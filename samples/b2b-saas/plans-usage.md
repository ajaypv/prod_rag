# NimbusFlow Plans and Usage Charges

This is fictional test documentation for the prodRAG demo.

## Subscription plans

The Starter plan includes 10 users, 50 GB of file storage, and 100,000 automation runs each
month. The Growth plan includes 50 users, 500 GB, and 1,000,000 automation runs. Enterprise
plans use limits written in the customer order form.

Plan upgrades take effect immediately. NimbusFlow prorates the remaining base subscription for
the current billing period. Plan downgrades take effect at the next renewal and do not generate
an immediate credit.

## Metered overages

Automation runs and file storage above the included allowance are metered. The usage page can
lag by up to four hours. Month-end overages appear on the next invoice, not the invoice for the
month in which the overage occurred.

Workspace owners can review daily totals at **Settings > Billing > Usage**. CSV exports use UTC
dates. A difference smaller than the most recent four hours is expected while events are still
being aggregated.

## Usage disputes

Support can explain plan allowances and aggregation delay from this guide. A human Billing
Operations agent must review suspected duplicate metering, contract-specific Enterprise limits,
or an overage dispute above USD 500. The customer should provide the workspace ID, invoice ID,
and affected UTC date range, but no payment credentials.
